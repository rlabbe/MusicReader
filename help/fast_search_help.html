Fast File Search:

Suppose you want to open

c:\\users\\you\\music\\classical\\Philip Glass\\movies\\Koyaanisqatsi - Vocal Score.pdf
That would be very tedious to browse to, and perhaps hard to find if you aren't sure what directory it is in. Instead, set your search path (see Setting Search Directory) to

c:\\users\\you\\music
and then type

gl ko
where the gl will match "Glass" and the ko will match "Koyaanisqatsi", because case doesn't matter. Search results update as you type each character, so you have immediate feed back on which files match. Order also doesn't matter: ko gl would find the same file, as would for example Ko gL. Diacritics also do not matter. You may have both Frédéric Chopin and Frederic Chopin in your file names, and fred will match either.

If you were unsure about the name of the directory, just type koya and you'll also find the file, since you probably don't have many files with koya in the name.

The strength of searching path and name is that you may have very similar named files in different directories, and you can still find the one you want. For example, if you have a file etude1.pdf in directory Chopin and etude_01.pdf in directory Liszt, you can easily find the one you want with, for example, ch et 1. The minimal number of characters you'll need to type depends on what files you have. In practice, since the search results update after every key press, you'll get quick visual indication. So you might start with etu to get anything with "etude" in the name, and then if there are too many to choose narrow it down to Chopin by pressing space and then ch (resulting in etu ch as the search term). That would give you all the Chopin etudes you have, and you could then just click the file you want.

When you have narrowed down the results and found the file you want, either double click on it to open, or if you want to open more than one file, multi-select them and then press the "OK" button.

Files are sorted in "natural order". That is, sorting is not strictly alphabetical, because then "etude10" would come before "etude2". Capitalization is also ignored, so "etude1" would be listed before "Etude2" even though "E" comes before "e".

Setting the Search Directory:

Click the "..." button to set the directory to search. This will open a file dialog where you can select the directory to search. When you close it the file list will be updated. The search will only look in this directory and its subdirectories.

Using Open File Dialog Instead

If you prefer to use the standard Windows open file dialog, click the "Open" button. This will open the standard Windows open file dialog, and you can navigate to the file you want.

If you want this to be the default behavior for the app when you press the file icon, uncheck "Use Fast Search" in the settings (in the main app). This setting will be remembered for the next time you run the app.
