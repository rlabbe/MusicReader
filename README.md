# MusicReader

I wrote this program to solve specific issues I have with viewing PDFs while playing piano. These may not match your concerns or needs. Oh well, this is for me, I'm just releasing it because I'm sure at least some people have these concerns. 

I wanted to solve the following problems:

* Score as big as possible (part I) - peering to distinguish notes slows down my sight reading - even when I don't have conscious issues with seeing the notes I still slow down and make mistakes when the score is small. And I don't want to fiddle with page sizes, zoom, all the stuff general PDF readers make you do. Page is always shown full size.

* Score as big as possible (part II) - menus, status bar, toolbar, and tabs are all hideable and/or movable. Monitors are wide, not tall, sheet music is tall, not wide. By default the toolbar and tabs are put on the side, where you will have free real estate. You can completely hide the menu (still accessible by right clicking app icon in titlebar), and the status bar, giving a bit more vertical space. F11 to fullscreen is also available. 

* Score as big as possible (part III) - Sheet music often has wide borders. Fixed borders make no sense on computers, IMO. The software will try to detect the blank space around the edges and zoom in to only show the music if the border feature is enabled. This doesn't alwasy work with poor quality scans with a lot of noise, such as some of the holographs from IMSLP. 

* Fast file search - I have a lot of pdfs organized in many directories. It can take time to drill through directories to find what you need. Fast file search indexes all pdfs, and then instantly finds the file you want - want Bach's prelude 934, but don't quite remember what it is called. No problem, open fast file search, type 'bac 934' and as you type all the files that have any of those characters will match - that is 'bac' will match back, '934' would match prelude_934.pdf, BWV-934, or whatever you named it. You can also just use the standard Windows open file dialog box if you prefer. 

* Fast open - some pdfs take a long time to open. While some PDF readers are pretty efficient, this is optimized to open at the last place you were open (if re-opening), and then it reads pages forwards and backwards from that point to maximize the chances when you press page fwd/back the page will already be loaded. It should be instant unless you jump 40 pages or such in a large document.

* Easy to use - again, for me. I have single key shortcuts for common things. Press B to create a bookmark, and immediately start typing to enter the name. Etc. No need for CTRL or using the mouse. 

* No file management - I dislike apps that make you use a propietary storage system. I already organized my files, I don't use them just with this app. A lot of you will dislike this, but again, my app, for me.

* Paging modes - We all suffered this - to save paper the publisher starts a movement (Minuette, whatever) at the bottom of the right page, requiring a page flip. These are usuall pieces that fit on 2 pages. How annoying. MusicReader has a 2 page mode that shows left/right pages side by side. However, there is an option that page up/down moves only 1 page at a time - move that minuet start to the left, and now you can see the entire piece on one screen, no page turn required. 

I tend to use this all the time. I always play only looking at the left side, and the right side is just there so I can briefly see what is coming up for the 'page turn'. Once I hit the right side, then I page turn (with a pedal) and keep reading on the left. Takes a few times to get used to it, then you basically never have a 'real' page turn except for multi-page repeats (I have plans to deal with this).
